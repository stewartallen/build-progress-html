# RV-10 Build Progress Tracker

A static HTML dashboard showing the construction progress of an RV-10 aircraft kit:
a GitHub-style contribution heatmap of daily build hours, plus eight statistics cards.

One file. No build step, no framework, no CDN — the only network request the page makes
is for its own `progress.json`.

## Features

- **Contribution heatmap** — hand-drawn SVG, one column per week, colour-scaled by hours
- **Eight statistics** — totals, averages, streaks, and two completion estimates
- **Light and dark** — follows the operating-system theme automatically
- **Responsive without breakpoints** — fluid type, and charts that scale down before they scroll
- **Auto-refresh** — every 15 minutes, paused while the tab is hidden
- **Resilient** — a failed refresh keeps the last good data on screen
- **Accessible** — landmarks, live status region, per-year chart summaries, reduced-motion support
- **Print-friendly**

## Quick start

```bash
# 1. Put progress.json next to index.html
# 2. Serve the directory
python3 -m http.server 8000    # or: npm run serve
# 3. Open http://localhost:8000
```

Any static web server works — nginx, Apache, Caddy, GitHub Pages, Netlify, Vercel.
Deployment is copying `index.html` and `progress.json` into place.

> `file://` will not work: the page fetches `progress.json`, which browsers block on the
> file protocol. Serve over HTTP.

## Data format

`progress.json` is generated by [`build-progress-cli`](../build-progress-cli):

```json
{
    "log": [
        { "date": "2022-02-02", "hours": 4.4 },
        { "date": "2022-02-03", "hours": 0.0 }
    ],
    "statistics": {
        "total_hours": 1528.4,
        "days_worked": 473,
        "avg_hours_per_week": 7.9,
        "avg_hours_last_6_weeks": 3.4,
        "est_completion_date": "2028-02-25",
        "est_completion_date_6_weeks": "2031-04-09",
        "hours_current_week": 0.0,
        "hours_current_month": 7.0,
        "hours_last_30_days": 14.8,
        "current_streak": 0,
        "record_streak": { "days": 9, "start_date": "2023-06-30" }
    }
}
```

Dates are ISO `YYYY-MM-DD` and are treated as UTC throughout. Days missing from `log`
render as zero-hour cells; days in the future are not drawn at all.

## The heatmap

Each year is one SVG: a column per week, a row per weekday. Hours map to five colour
levels:

| Level | Hours   | Dark      | Light     |
| ----- | ------- | --------- | --------- |
| 0     | 0       | `#30363d` | `#ebedf0` |
| 1     | 0.1 – 2 | `#0e4429` | `#9be9a8` |
| 2     | 2 – 4   | `#006d32` | `#40c463` |
| 3     | 4 – 6   | `#26a641` | `#30a14e` |
| 4     | 6+      | `#39d353` | `#216e39` |

Hover any cell for the exact date and hours. Years are listed newest first.

## Statistics

| Card                           | Shows                                           |
| ------------------------------ | ----------------------------------------------- |
| Total Hours                    | Total, plus % of the goal and hours remaining   |
| Days Worked                    | Days with at least one session                  |
| Average Per Week               | Overall average, plus the last-6-week trend     |
| Current Week                   | This week, plus this month and the last 30 days |
| Est. Completion                | Projected from the overall average              |
| Est. Completion (6-week trend) | Projected from recent pace                      |
| Current Streak                 | Consecutive days worked                         |
| Record Streak                  | Longest streak, and when it started             |

## Configuration

Edit the `CONFIG` block near the top of the `<script>` in `index.html`:

```js
const CONFIG = Object.freeze({
    dataUrl: 'progress.json',
    goalHours: 2500,
    refreshMs: 15 * 60 * 1000,
    requestTimeoutMs: 15_000,
});
```

Colours live in the `:root` token block at the top of the `<style>`; the heatmap
thresholds are `LEVEL_CUTOFFS`.

## Development

Tooling is for contributors only — the page itself ships zero dependencies.

```bash
npm install
npm run serve   # local server on :8000
npm run check   # prettier --check && eslint
npm run fix     # prettier --write && eslint --fix
```

Run `npm run fix` before committing.

## Browser support

Current Chrome, Edge, Firefox, and Safari. The page uses ES modules, `AbortSignal.timeout()`,
`Array.prototype.findLast()`, and CSS `clamp()` / custom properties / logical properties.
